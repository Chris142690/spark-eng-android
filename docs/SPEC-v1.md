# CCG 单词 App · 设计规格 v1（DSH × ChatGPT 第三轮定稿）

日期：2026-11-05　状态：待实现（原生 Android）

## 0. 起点修正（关键）
- 用户清空前背到 800 词，**自述「都没记住」** → 起点按 **0** 算，不剔除任何"已会"词。
- 959 天签到 = 启动习惯已成型；8384 分钟 = 历史累计，非当前预算。
- 真正问题不是"让他多背 800 个词"，而是**第一次让他体验到"昨天学的今天还记得"**。
- 时间基准：**核心任务 10–15 分钟**，允许额外投入，但绝不假设每天有 40 分钟。

## 0.1 词量预算
- **840 个学习单元** = 700 高频核心词 + 140 高价值搭配/句型表达。
- 每天 2 个新单元 × 420 天 = 840。
- 840 是**词汇学习预算，不是 A2 能力保证**。必须配能力验收：
  - 每周听懂一段 A2 材料
  - 每周独立读一篇短文
  - 每周两次情境口语
  - 每周一次短文写作
  - 每 30 天一次无提示综合测试

## 1. 首页（必须保留，但不是仪表盘）
结构（自上而下）：
```
11月5日
今天，先学一点

┌─────────────────────┐
│  主要入口 · 复习      │
│  下一张待复习          │
│  schedule            │
│  点击卡片，直接开始复习  │
└─────────────────────┘

  [ 学新词 ]
  从今天的第一个词开始，不赶进度

今天的英语小知识  ▸
```
**必须删除**：还剩 N 张 / 今日完成 12/25 / 连续签到 959 天 / 总词汇进度百分比 / 逾期卡片数量 / **完成环**（会暗示未完成目标）。

> 首页不是成绩单，而是启动器。

- 无到期复习时：中间卡位显示「今天暂时没有需要复习的卡片」，新授入口成为视觉主入口。
- **没有第三个「开始」按钮**——预览卡本身就是复习入口，下方按钮就是新授入口。

## 2. 双入口架构
| 模块 | 最终决定 |
|---|---|
| 首页 | 必须保留 |
| 复习入口 | 一张可点击的预览卡（点击=直接进复习） |
| 新授入口 | 独立按钮（点击=直接进新授） |
| 复习队列 | 只显示到期复习卡 |
| 新授队列 | 新卡及短期学习卡 |

| 首页进度 | 定性状态，不展示债务数字 |
| 今日小知识 | 折叠在底部 |

## 3. 新授流程（四步，先建立表征不先猜）
对连 A2 单词多数无法正确发音的人，**强制猜词会增加无效认知负担**。

1. **声音与拼写同时呈现**：自动播放美式发音，屏幕同步显示完整单词。
2. **展示音标与发音结构**：标注音节、重音、关键音素。IPA 是辅助，不要求初学者直接解读。
3. **建立语义**：词性、中文释义、常用搭配、一个例句 + 翻译。
4. **主动提取**：隐藏部分提示，让用户尝试回忆，答完再评价。

**关键算法区分：首次编码 ≠ FSRS 首次评分**
- 初次呈现：不评分、不修改 FSRS 记忆参数。
- 完成教学后：进行第一次真正的主动回忆，此时才提交 Again/Hard/Good。
- 之后由 FSRS 进入 Learning 状态，按短期学习步骤调度。
- 完成学习阶段后进入普通 Review 队列。

理由：FSRS 新卡首次评分会初始化 stability 与 difficulty，必须保证评分来自真正回忆，而非刚看完答案的熟悉感。

> **教学流程独立，记忆调度不独立。两套 UI 入口，共用一套 FSRS 引擎。**

另：不要为制造"学习感"让新词在十分钟内重复十几遍（Anki 官方文档同样建议减少学习步骤）。

## 4. 评分：三档
| 用户操作 | FSRS 映射 |
|---|---|
| 完全想不起来 | Again (1) |
| 费力回忆成功 | Hard (2) |
| 独立、顺畅回忆 | Good (3) |

**暂时关闭 Easy**。反应时间只作异常检测，不直接覆盖用户评分；首周收集 50 次有效复习记录再校准评分习惯。

（对 Hard 的技术纠正：Hard ≠ 稳定性完全不增长，只是相较 Good 获得更短的复习间隔。）

## 5. 队列与上限
- **硬上限 25 张，包含新词**。
- **复习优先**，新词动态调整：先 2 个/天启动，观察真实复习负荷再增至 3。
- **漏学不产生翻倍任务，不设补课债务**。
- **20 张不是最低完成要求**；状态差时完成 5 张也允许。
- 25 是**硬上限**，不是每日任务。
- 排序：①是否已到期 ②当前预期可回忆率 retrievability ③逾期程度 ④历史遗忘次数（仅辅助）。
- **难卡分散**：每 4–5 张穿插一张高难度卡；不设"最后 5 张最难"，不为凑数打乱 FSRS 正常调度。
- 完成一次有效学习 ≠ 清空所有到期卡片。

## 6. 首页状态文案（只显示状态，不显示数量）
| 用户状态 | 首页反馈 |
|---|---|
| 今天还没学习 | 今天先学一点 |
| 已完成一次有效学习 | 今天已经学过了 |
| 主动结束本次学习 | 今天先到这里，明天继续 |

> 959 天打开说明有稳定启动习惯，但过去没把启动转化为词汇掌握。继续奖励签到数字，可能只会强化旧行为。

## 7. 第一周验收指标（不是"连续打开七天"）
1. 打开 App 至首次进入卡片 ≤ **10 秒**
2. 打开 App 至第一次有效回忆 ≤ **30 秒**
3. 进入卡片后是否完成第一次作答
4. 是否愿意主动进入第二张卡
5. **次日是否还能正确回忆前一天学过的词**（最关键）

## 8. FSRS-4.5 参数（沿用）
```
W = [0.4872,1.4003,3.7145,13.8206,5.1618,1.2298,0.8975,0.031,
     1.6474,0.1367,1.0461,2.1072,0.0793,0.3246,1.587,0.2272,2.8755]
DECAY = -0.5 ; FACTOR = 19/81
R(t,S) = (1 + FACTOR*t/S)^DECAY
I(S,r) = S * (r^(1/DECAY) - 1) / FACTOR     # r=0.9 时 I=S
```
